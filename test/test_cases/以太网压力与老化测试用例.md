# 以太网压力与老化测试专项

本专项验证设备以太网、DHCP、TCP/IP 协议栈和网络管理服务在长时间及异常网络条件下的稳定性。它不替代基础网络功能验收。

## 测试环境

准备可配置交换机、DHCP 服务、测试 PC、流量发生器或 `iperf3`。记录设备 MAC、IP、交换机端口、固件版本和测试时长。默认老化时长为 72 小时，正式版本以测试计划为准。

| 编号 | 测试内容 | 验收标准 | 结果 |
| --- | --- | --- | --- |
| ETH-AGING-001 | 72 小时连续运行 | 无异常复位、卡死、内存持续增长或网络服务退出 | |
| ETH-AGING-002 | 持续双向流量 | 流量持续可用，丢包和错误不超过发布阈值 | |

| ETH-AGING-005 | 异常流量 | 广播、半连接和突发流量不会导致设备失活 | |

## 详细用例

### ETH-AGING-001 72 小时连续运行

1. 设备上电并确认网络 ready。
2. 每 1 分钟执行一次 ping，每 10 分钟读取一次网络状态。
3. 连续运行 72 小时，记录复位、断链、地址变化和可观测资源数据。

预期：设备不异常重启、不失去网络管理能力；网络统计计数持续合理增长，不能出现无法解释的资源耗尽。

### ETH-AGING-002 持续双向流量

1. 使用 `iperf3` 进行 TCP 上行和下行持续流量。
2. 每 6 小时切换一次方向，并同时保持 ping。

预期：吞吐不持续下降，丢包、重传、连接错误和链路错误低于发布阈值；设备仍可响应维护连接。

### ETH-AGING-003 链路反复上下线

1. 以 30 秒在线、30 秒断线为一个周期。
2. 重复至少 100 次。
3. 每次恢复后确认 DHCP/IP、ping 和 Telnet 状态。

预期：每次链路恢复最终进入 ready；连接、线程和缓冲区不会因重复上下线持续泄漏。

### ETH-AGING-004 DHCP 租约续租

1. 将 DHCP 租约设置为测试允许的较短周期。
2. 持续运行覆盖至少 3 次续租。

预期：续租成功，地址和网关状态正确；续租失败时按策略重试，不阻塞其他系统功能。

### ETH-AGING-005 异常流量

1. 使用流量发生器发送广播、突发 TCP 连接和连接建立/关闭压力。
2. 同时保持一条正常管理连接。

预期：设备不死机、不异常复位；达到资源上限时拒绝新增流量，但保留恢复能力。

### ETH-AGING-006 老化后业务恢复

1. 停止流量并等待 5 分钟。
2. 执行 ping、Telnet 和 Modbus TCP 读操作。

预期：所有基础业务仍可用，状态和统计接口可访问，设备无需重新刷写固件。

## 判定与缺陷证据

记录测试起止时间、链路次数、DHCP 日志、流量统计、丢包/重传、复位原因、网络状态和老化前后资源数据。出现异常复位或不可恢复断链时判定失败。
