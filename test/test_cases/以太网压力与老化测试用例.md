# 以太网压力与老化测试用例

## 1. 测试信息

- 目的：验证以太网长期运行、持续收发、链路抖动和恢复能力。
- 执行人：________  固件版本：________  板卡编号：________  日期：________
- 测试前由开发人员填写：老化时长 ______ h；目标吞吐 ______ Mbps；允许丢包率 ______%；允许重连次数 ______。
- 工具：被测板、稳定电源、交换机、PC、网线、`ping`、`iperf3`、串口终端、抓包工具（可选）。
- 注意：链路断开和断电操作按硬件安全要求执行；异常重启、看门狗复位必须保留日志。

## 2. 用例

| 编号 | 内容 | 通过条件 |
|---|---|---|
| ETH-AGE-001 | 空闲长期运行 | 达到时长、无异常复位 |
| ETH-AGE-002 | 持续双向流量 | 吞吐和错误率达标 |
| ETH-AGE-003 | 链路断开恢复 | 在阈值内恢复 |
| ETH-AGE-004 | 网络设备重启恢复 | 自动恢复通信 |

### ETH-AGE-001 空闲长期运行
1. 上电，串口执行 `net iface`，确认接口为 UP、carrier 为 ON，并记录 IP。
2. PC 持续 `ping <device_ip> -t`，同时每 30 分钟执行一次 `net iface`。
3. 持续运行规定老化时长，记录丢包、接口状态、异常日志和复位次数。
4. 通过标准：接口持续可用；丢包率不超过开发人员给出的阈值；无未解释复位。

### ETH-AGE-002 持续双向流量
1. PC 执行 `iperf3 -s`；被测设备按项目提供的 iperf 客户端方式连接 `iperf3 -c <pc_ip> -t <duration> -i 10`。
2. 进行上行、下行和双向测试各一轮，记录吞吐、重传、错误和接口状态。
3. 通过标准：持续时间达到要求，无连接失效；吞吐和错误率满足项目阈值。

### ETH-AGE-003 链路反复断开恢复
1. 建立 `ping` 和业务流量。
2. 按测试表每轮拔插网线或关闭交换机端口，保持断开 ______ s 后恢复，共 ______ 轮。
3. 每轮记录断开检测时间、恢复时间、丢包数量和是否需要人工重启。
4. 通过标准：恢复时间不超过 ______ s；恢复后可继续通信；无死锁。

### ETH-AGE-004 网络设备重启恢复
1. 建立持续 `ping`，记录被测设备当前状态。
2. 重启交换机或 DHCP 服务，等待网络恢复。
3. 检查 `net iface`、设备 IP、MQTT/Modbus 连接（若启用）。
4. 通过标准：设备不需要断电即可恢复，未产生异常持续占用或卡死。
