# 惯性测量单元测试用例

## 1. 测试信息

- 模块：`module/imu_sample_service`。开发人员填写量程、采样率、静态输出范围和误差阈值 ______。
- 工具：水平安装工装、角度/振动测试设备、串口/MQTT Shell。

## 2. 用例

| 编号 | 内容 | 通过条件 |
|---|---|---|
| IMU-001 | 静态六面体 | 重力方向和零偏达标 |
| IMU-002 | 已知转动 | 方向、量程和误差达标 |
| IMU-003 | 采样稳定性 | 周期、丢样和错误达标 |
| IMU-004 | 接口异常恢复 | 故障可识别且采样恢复 |

### IMU-001 静态六面体
1. 将设备依次放置在六个正交面，每个面稳定 ______ s。
2. 记录加速度、角速度、姿态（若提供）和错误状态。
3. 通过标准：重力方向与安装面一致，静态角速度接近零，均满足阈值。

### IMU-002 已知转动
1. 使用角度工装以 ______ deg/s、______ deg/s 转动。
2. 记录输出频率、方向、峰值和积分角度。
3. 通过标准：方向、量程和误差满足测试计划，无数据停滞。

### IMU-003 采样稳定性
1. 连续采样 ______ min，统计样本数、时间戳间隔、丢样和错误数。
2. 通过标准：采样周期误差、丢样率和错误数在阈值内。

### IMU-004 接口异常恢复
1. 在安全条件下断开 IMU 接口，观察错误输出。
2. 恢复连接并观察 ______ s。
3. 通过标准：故障可识别，恢复后采样重新正常。
