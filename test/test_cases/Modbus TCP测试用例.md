# Modbus TCP测试用例

## 1. 测试信息

- 开发人员提供并填写：设备 IP ______；端口 ______；Unit ID ______；寄存器表版本 ______；地址基准（0/1）______。
- 工具：Modbus TCP 客户端、抓包工具、串口终端。所有地址、数据类型、读写权限以寄存器表为准。

## 2. 用例

| 编号 | 内容 | 通过条件 |
|---|---|---|
| MODBUS-001 | 建立连接 | 连接和协议字段正确 |
| MODBUS-002 | 读取寄存器 | 地址、字节序和值正确 |
| MODBUS-003 | 写入参数 | 写入、读取和恢复正确 |
| MODBUS-004 | 非法请求 | 返回异常且不崩溃 |
| MODBUS-005 | 并发和重连 | 连接互不干扰 |

### MODBUS-001 建立连接
1. PC 使用指定 IP、端口和 Unit ID 连接设备。
2. 记录连接结果、响应时间和抓包中的事务标识。
3. 通过标准：连接成功，端口和协议字段正确。

### MODBUS-002 读取只读寄存器
1. 按寄存器表选择一个整数、一个浮点或状态寄存器。
2. 使用对应功能码读取，换算数据并与串口/现场值比较。
3. 通过标准：地址、长度、字节序和数值均正确。

### MODBUS-003 写入可写参数
1. 先读取并记录原值；写入测试值；再次读取确认。
2. 执行 `param status`（若参数映射到参数服务），确认变更状态符合设计。
3. 恢复原值并按设计保存，避免污染后续测试。

### MODBUS-004 非法请求
1. 访问不存在地址、错误长度、禁止写入地址和不支持功能码。
2. 记录异常码、连接状态和设备日志。
3. 通过标准：返回定义的异常响应，不崩溃、不修改其他寄存器。

### MODBUS-005 并发和重连
1. 使用两个客户端同时读取，随后断开一个并重新连接。
2. 检查另一连接和设备 Shell 是否仍可响应。
3. 通过标准：连接互不干扰，重连后事务正常。
