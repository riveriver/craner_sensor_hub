# 以太网性能测试用例

## 1. 测试信息

- 目的：量化链路协商、时延、吞吐、丢包和并发通信性能。
- 工具：被测板、PC、交换机、`ping`、`iperf3`、串口终端；测试参数由开发人员填写：期望速率 ______，时延上限 ______ ms，丢包上限 ______%。

## 2. 用例

| 编号 | 内容 | 通过条件 |
|---|---|---|
| ETH-PERF-001 | 链路协商 | 速率、双工和地址正确 |
| ETH-PERF-002 | 时延和丢包 | 所有网络阈值达标 |
| ETH-PERF-003 | 单连接吞吐 | 上下行达到目标 |
| ETH-PERF-004 | 并发流量 | 业务不失联 |
| ETH-PERF-005 | 抓包一致性 | 报文无异常 |

### ETH-PERF-001 链路协商
1. 上电后执行 `net iface`。
2. 记录接口名称、MTU、速率、双工、carrier、IP 和网关。
3. 通过标准：与硬件设计速率一致，接口为 UP，地址正确。

### ETH-PERF-002 时延和丢包
1. PC 执行 `ping <device_ip> -n 1000`。
2. 记录最小/平均/最大时延和丢包率，重复 3 次。
3. 通过标准：均值、最大值和丢包率均不超过项目阈值。

### ETH-PERF-003 单连接吞吐
1. PC 执行 `iperf3 -s`。
2. 被测设备运行项目提供的 iperf 客户端，分别测试 TCP 上行和下行，每次 ______ s。
3. 记录吞吐、重传和错误；与目标速率比较。

### ETH-PERF-004 并发流量
1. 使用 `iperf3 -c <device_ip> -P <streams> -t <duration>` 或项目指定等效工具。
2. 逐步使用 ______、______、______ 条并发流，记录吞吐、CPU/内存异常和业务通信情况。
3. 通过标准：达到目标并发时业务不失联、无异常复位。

### ETH-PERF-005 抓包一致性
1. 在交换机镜像口抓包，运行一次 Modbus/MQTT 业务请求。
2. 核对源/目的 MAC、IP、端口、重传、校验错误和报文时序。
3. 通过标准：报文符合协议，未出现异常广播、重复风暴或大量重传。
