# 以太网性能测试专项

本专项测量设备以太网链路和 TCP/IP 通信性能。具体带宽、延迟和丢包阈值由硬件规格或产品发布标准提供。

## 测试环境

使用千兆/百兆可配置交换机、测试 PC、`iperf3`、ping 和 Wireshark。测试 PC 与设备直连或经过交换机时应分别记录。

## 验收概览

| 编号 | 测试内容 | 验收标准 | 结果 |
| --- | --- | --- | --- |
| ETH-PERF-001 | 链路协商 | 速率和双工状态符合硬件预期 | |
| ETH-PERF-002 | TCP 吞吐 | 上下行吞吐达到发布阈值 | |
| ETH-PERF-003 | UDP 丢包 | 不同负载下丢包和抖动符合阈值 | |
| ETH-PERF-004 | ICMP 延迟 | 空载和负载下延迟符合阈值 | |
| ETH-PERF-005 | 并发连接 | 并发连接数和恢复时间符合配置 | |
| ETH-PERF-006 | 业务共存 | 流量压力下 Shell 和 Modbus TCP 可用 | |

## 详细用例

### ETH-PERF-001 链路协商

1. 在交换机上确认设备端口的速率、双工和错误计数。
2. 分别测试自动协商和产品支持的固定速率。

预期：协商结果符合硬件规格，无 CRC、丢帧或 duplex mismatch。

### ETH-PERF-002 TCP 吞吐

1. 使用 `iperf3` 测试设备到 PC 的 TCP 吞吐。
2. 反向测试 PC 到设备的 TCP 吞吐。
3. 分别测试 1、4、8 条并行流。

预期：吞吐达到开发者提供的下限，增加并行流不会导致设备异常或管理面失联。

### ETH-PERF-003 UDP 丢包

1. 以低于、等于和高于目标带宽的速率发送 UDP。
2. 记录丢包率、抖动和乱序。

预期：目标带宽内指标符合阈值；超载时可丢包但设备必须保持可恢复和可管理。

### ETH-PERF-004 ICMP 延迟

1. 空载执行 1000 次 ping。
2. 在 TCP/UDP 满载时重复执行。

预期：记录平均、最大延迟和丢包率；负载下仍不出现持续超时或网络服务退出。

### ETH-PERF-005 并发连接

1. 逐步增加 TCP 并发连接至产品允许上限。
2. 继续增加连接直到达到拒绝条件。
3. 关闭全部连接后重新建立管理连接。

预期：设备按资源上限处理连接，拒绝行为可预测；资源释放后恢复时间符合阈值。

### ETH-PERF-006 业务共存

1. 在持续流量期间保持 Telnet 和 Modbus TCP 连接。
2. 每分钟读取一次状态和寄存器。

预期：业务请求响应时间、错误率和网络统计符合阈值，互不造成异常阻塞。

## 判定与缺陷证据

记录链路速率、测试拓扑、iperf3 命令、吞吐、并发流、延迟、丢包、抖动、Wireshark 摘要和业务请求错误率。
