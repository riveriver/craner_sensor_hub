# 时间管理测试用例

实现：`module/time_manager_service`。具体时间源和服务器以产品配置为准。

## 验收概览

| 编号 | 测试内容 | 验收标准 | 结果 |
| --- | --- | --- | --- |
| TIM-001 | 启动时间状态 | 无有效时间源时状态明确 | |
| TIM-002 | NTP 同步 | 网络 ready 后可同步并更新质量 | |
| TIM-003 | RTC 恢复 | 有效 RTC 可在重启后恢复时间 | |
| TIM-004 | 手动设置 | 合法时间可设置，非法输入被拒绝 | |
| TIM-005 | 时间连续性 | 正常运行期间时间单调递增 | |

## 详细用例

### TIM-001 启动时间状态

1. 在无 NTP、无有效 RTC 的条件下启动设备。
2. 查询时间状态。

预期：时间源和质量明确，系统仍可启动，不把无效时间误报为已同步。

### TIM-002 NTP 同步

1. 接入网络并提供可用 NTP 服务。
2. 等待同步后读取时间状态和日志时间戳。

预期：时间源为 NTP，质量达到配置要求，失败时按策略重试。

### TIM-003 RTC 恢复

1. 设置有效 RTC 时间后断电。
2. 重新上电并在网络不可用时读取系统时间。

预期：恢复 RTC 时间并标记为对应可信质量。

### TIM-004 手动设置

1. 设置合法 ISO8601 时间。
2. 分别输入错误格式、越界日期和空值。

预期：合法输入成功，非法输入被拒绝且原时间不被破坏。

### TIM-005 时间连续性

1. 连续读取时间和日志时间戳 10 分钟。

预期：时间单调递增，格式、时区和精度符合发布约定。

## 缺陷证据

附时间源、NTP 配置、RTC 初始值、命令输出、同步时间和前后状态。
