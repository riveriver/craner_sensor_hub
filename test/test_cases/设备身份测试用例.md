# 设备身份测试用例

实现：`module/device_identity_service`。

## 验收概览

| 编号 | 测试内容 | 验收标准 | 结果 |
| --- | --- | --- | --- |
| ID-001 | UID 稳定性 | 同一设备重启后 short UID 不变 | |
| ID-002 | MAC 唯一性 | MAC 格式正确且不同设备不重复 | |
| ID-003 | hostname/mDNS | 名称符合发布规则且可解析 | |
| ID-004 | 身份关联 | MQTT Client ID 与设备身份一致 | |

## 详细用例

### ID-001 UID 稳定性

1. 记录设备 short UID。
2. 冷启动 3 次并再次读取。

预期：同一设备每次生成结果一致。

### ID-002 MAC 唯一性

1. 记录 MAC 格式和地址。
2. 对多台设备重复测试并与硬件标签比对。

预期：MAC 格式符合产品约定，不重复、不随机变化。

### ID-003 hostname/mDNS

1. 在同一网络查询设备 hostname 和 `.local` 名称。
2. 使用 ping 或 DNS 工具解析。

预期：名称符合发布规则，解析结果指向设备当前 IP。

### ID-004 身份关联

1. 在 MQTT 或状态上报中读取 Client ID。
2. 与 hostname、short UID 和 MAC 比对。

预期：身份字段来自同一设备，格式和内容一致。

## 缺陷证据

附设备标签、UID、MAC、hostname、解析结果、固件版本和测试网络信息。
