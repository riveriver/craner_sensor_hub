# 设备身份测试用例

实现：`module/device_identity_service`。使用 Telnet 或 MQTT Shell 执行，不要求阅读源码。

## 前置输入

填写产品默认 company/model/product、设备 IP/hostname、固件版本和硬件标签。测试前确认允许执行 `param factory_reset`。

## 详细用例

### ID-001 身份字段读取

1. 执行 `id show`。
2. 记录 `hardware_uid`、`short_id`、`long_id`、`hostname`、`mdns`、`mqtt_client_id` 和 `mac`。

预期：`short_id` 为 6 位小写十六进制；`long_id` 为 12 位连续小写十六进制；MAC 为标准 6 字节格式；所有字段非空且与产品默认身份规则一致。

### ID-002 重启稳定性

1. 执行 `id show` 并记录所有身份字段。
2. 重启设备，等待网络恢复。
3. 再次执行 `id show` 并逐项比较。

预期：`hardware_uid`、`short_id`、`long_id`、MAC 和名称均保持不变。

### ID-003 参数身份联动

1. 执行 `param factory_reset`，重启设备。
2. 执行：

   ```text
   param set id.company test-company
   param set id.model test-model
   param set id.product test-product
   param save
   ```

3. 确认返回 `status=ok` 后重启。
4. 执行 `param list` 和 `id show`。

预期：三个参数保持测试值，`id show` 中 company/model/product 与其一致；硬件 UID、short_id、long_id 和 MAC 不变。

恢复：执行 `param factory_reset`，重启并再次执行 `id show`。

### ID-004 多设备唯一性

1. 对至少 3 台设备执行 `id show`。
2. 记录每台的 short_id、long_id、MAC 和 hardware_uid。

预期：每台设备的硬件 UID、short_id、long_id 和 MAC 均不重复。
