# 风速仪测试用例

## 1. 测试信息

- 模块：`module/anemometer_sample_service`。开发人员填写通信接口、量程、标准风速点、允许误差和超时阈值 ______。
- 工具：风速校准装置/风洞、串口/MQTT Shell、计时器。

## 2. 用例

| 编号 | 内容 | 通过条件 |
|---|---|---|
| ANEMO-001 | 零风基线 | 零点和通信状态达标 |
| ANEMO-002 | 标准风速点 | 各点误差达标 |
| ANEMO-003 | 超时和断线 | 可报错且可恢复 |
| ANEMO-004 | 连续采样 | 数据连续、错误受控 |

### ANEMO-001 零风基线
1. 在无风条件稳定 ______ s。
2. 记录风速、风向（若提供）、质量状态和错误次数。
3. 通过标准：输出在零点阈值内，无误报通信故障。

### ANEMO-002 标准风速点
1. 依次施加 ______、______、______ m/s 标准风速，各保持 ______ s。
2. 记录稳定值、响应时间和误差。
3. 通过标准：每个点误差不超过阈值，响应时间合格。

### ANEMO-003 通信超时和断线
1. 运行采样时断开风速仪或停止响应，观察一个超时周期。
2. 记录错误码、重试间隔和系统其他服务状态。
3. 恢复连接，确认数据恢复。
4. 通过标准：出现可读错误，不阻塞系统；恢复后自动采样。

### ANEMO-004 连续采样
1. 在标准风速点连续采样 ______ min。
2. 统计样本数、跳变、超时和错误次数。
3. 通过标准：无异常累计错误，数据连续且符合阈值。
