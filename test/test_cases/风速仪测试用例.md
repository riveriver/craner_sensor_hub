# 风速仪测试用例

实现：`module/anemometer_sample_service`、`app/anemometer_app`。

## 验收概览

| 编号 | 测试内容 | 验收标准 | 结果 |
| --- | --- | --- | --- |
| WND-001 | 环境数据采样 | 温度、湿度和气压值正确 | |
| WND-002 | 风况数据采样 | 风速和风向值正确 | |
| WND-003 | 边界值 | 范围、比例和符号符合协议 | |
| WND-004 | 离线恢复 | 无响应和恢复状态正确 | |

## 详细用例

### WND-001 环境数据采样

1. 使用模拟器依次设置温度、湿度和气压。
2. 读取风速仪对应数据寄存器。

预期：数值、单位、比例、字节序和时间戳正确。

### WND-002 风况数据采样

1. 设置 0、正常值和最大风速。
2. 设置 0、180、359 度及边界风向。

预期：风速和风向与输入一致，方向范围符合发布协议。

### WND-003 边界值

1. 发送最小值、最大值、负值和非法编码。

预期：合法边界值可正确转换，非法值被拒绝或按发布约定标记错误。

### WND-004 离线恢复

1. 停止风速仪响应并等待离线阈值。
2. 恢复响应并观察后续采样。

预期：离线状态和健康事件正确变化，恢复后五类数据重新更新。

### WND-005 采样统计

1. 执行稳定采样，再发送异常帧。
2. 查询风速仪统计入口。

预期：成功数、失败数、连续失败数和耗时统计正确。

### WND-006 Modbus 映射

1. 读取风速仪时间戳、错误码、离线状态和五类数据寄存器。
2. 与模拟器输入逐项比对。

预期：所有字段映射正确，风速仪故障不影响其他采样服务。

## 缺陷证据

附风速仪型号、模拟器输入、原始帧、寄存器响应、统计输出和复现次数。
