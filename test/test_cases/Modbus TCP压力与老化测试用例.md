# Modbus TCP压力与老化测试用例

## 1. 测试信息

- 开发人员填写：持续时间 ______ h；并发客户端 ______；请求速率 ______ req/s；允许错误率 ______%；端口/Unit ID ______。
- 工具：支持定时、并发、异常请求统计的 Modbus TCP 测试工具，PC、交换机、串口终端、抓包工具。

## 2. 用例

| 编号 | 内容 | 通过条件 |
|---|---|---|
| MODBUS-AGE-001 | 持续轮询 | 错误率和响应时间达标 |
| MODBUS-AGE-002 | 并发客户端 | 无复位，响应达标 |
| MODBUS-AGE-003 | 断连重连 | 资源回收且可重连 |
| MODBUS-AGE-004 | 异常报文压力 | 合法业务不受影响 |

### MODBUS-AGE-001 持续轮询
1. 按寄存器表建立读请求集合，循环执行 ______ h。
2. 每小时记录成功数、超时数、异常响应、平均/最大响应时间和设备状态。
3. 通过标准：无死锁、无持续超时增长，统计值满足阈值。

### MODBUS-AGE-002 并发客户端
1. 启动 ______ 个客户端，每个按 ______ req/s 轮询。
2. 运行 ______ min，期间观察 `net iface` 和 Shell 响应。
3. 通过标准：连接数和响应时间满足阈值，无异常复位。

### MODBUS-AGE-003 断连重连
1. 让客户端每 ______ s 建立连接并在 ______ 次请求后主动断开，共 ______ 轮。
2. 记录连接失败、超时、残留连接和恢复时间。
3. 通过标准：资源可回收，重连后数据正常。

### MODBUS-AGE-004 异常报文压力
1. 在隔离网络发送非法功能码、错误长度、非法地址和半包/粘包请求。
2. 记录异常响应和设备日志，测试结束后恢复正常客户端轮询。
3. 通过标准：只拒绝异常请求，不影响系统和其他合法客户端。
