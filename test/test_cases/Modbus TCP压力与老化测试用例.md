# Modbus TCP 压力与老化测试专项

本专项验证 `module/modbus_tcp_server` 和产品寄存器适配在并发、持续请求、异常报文和长时间运行下的稳定性。

## 测试环境

准备至少 5 个 Modbus TCP 客户端、OpenModScan 或脚本客户端、网络流量工具和发布寄存器表。确认服务器端口、Unit ID、地址基准、最大客户端数和各类请求上限。

## 详细用例

### MBTCP-AGING-001 单客户端长时间轮询

1. 使用一个客户端连续读取输入寄存器和 holding register。
2. 每 100 ms 发起一次请求，持续 24 小时。
3. 每小时记录响应时间、异常码和服务统计。

预期：请求成功率达到发布阈值，无持续延迟增长、线程退出或设备复位。

### MBTCP-AGING-002 最大并发压力

1. 同时建立配置允许的最大客户端数。
2. 每个客户端交替读取不同地址区域。
3. 持续运行至少 2 小时。

预期：所有连接按配置服务，响应 transaction ID 不串包，错误率和延迟符合阈值。

### MBTCP-AGING-003 超限连接

1. 在已有最大客户端数时继续建立额外连接。
2. 反复执行 50 次超限连接尝试。

预期：额外连接被拒绝或关闭，已有客户端不掉线；服务统计记录拒绝原因。

### MBTCP-AGING-004 混合功能码压力

1. 混合发送 coil 读写、input 读取、holding 读写和非法请求。
2. 以 1:1:1:1 的比例持续运行 1 小时。

预期：合法请求保持正确，非法请求返回标准异常码，不导致后续请求失败或服务重启。

### MBTCP-AGING-005 断线重连压力

1. 客户端建立连接后随机等待 1 至 10 秒并主动关闭。
2. 立即重新连接并读取已知寄存器。
3. 重复 1000 次。

预期：连接槽位正确释放，新连接可用，无 socket、线程或内存资源持续耗尽。

### MBTCP-AGING-006 24/72 小时老化

1. 使用 3 个客户端持续轮询，间歇执行断线重连。
2. 测试时长按发布计划执行，默认 72 小时。
3. 每小时记录服务统计和业务可用性。

预期：无异常复位、卡死、响应持续恶化、统计溢出或不可恢复连接失败。

### MBTCP-AGING-007 持久化写入压力

1. 仅对发布表中允许持久化的 holding register 写入值。
2. 按配置等待延迟保存，期间混合读取请求。
3. 重启并核对恢复值。

预期：持久化写入不阻塞协议服务，重启后值正确；非持久化寄存器不被错误保存。

## 判定与缺陷证据

记录客户端数量、请求总数、成功率、异常码、P50/P95/P99 延迟、连接拒绝数、断线次数、服务统计、复位原因和老化前后资源数据。
