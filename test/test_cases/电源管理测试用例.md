# 电源管理测试用例

## 1. 测试信息

- 目的：确认上电、供电轨、外设电源控制和异常供电条件下的行为。
- 开发人员必须先填写：各电源轨名称/额定值/容差 ______；允许启动时间 ______ ms；外设开关命令 ______。
- 工具：可调电源、万用表/示波器、串口终端、负载和安全电源线。

## 2. 用例

| 编号 | 内容 | 通过条件 |
|---|---|---|
| POWER-001 | 上电启动 | 启动时间和服务状态达标 |
| POWER-002 | 电源轨测量 | 电压、峰值和纹波达标 |
| POWER-003 | 外设电源开关 | 状态正确且不死锁 |
| POWER-004 | 断电再上电 | 参数和业务恢复 |

### POWER-001 上电启动
1. 按额定输入电压上电，记录从上电到 Shell 可响应的时间。
2. 执行 `id show`、`net iface` 和 `param status`。
3. 通过标准：启动时间在阈值内，关键服务初始化成功，无异常复位。

### POWER-002 电源轨测量
1. 使用万用表/示波器依次测量每个电源轨的静态值、启动峰值和纹波。
2. 将结果填入附录，禁止超过硬件额定范围。
3. 通过标准：所有测量值满足硬件测试计划。

### POWER-003 外设电源开关
1. 执行开发人员提供的外设电源开/关命令，分别重复 ______ 次。
2. 每次记录电源轨变化、外设响应和 Shell 是否仍可用。
3. 通过标准：开关状态与命令一致，无误关其他电源、死锁或异常复位。

### POWER-004 断电再上电
1. 在空闲和正常业务状态各执行一次断电再上电。
2. 等待启动完成，检查 `param status`、`net iface`、传感器和 Modbus/MQTT 业务。
3. 通过标准：设备恢复正常；已保存参数不丢失；未产生未解释故障记录。
