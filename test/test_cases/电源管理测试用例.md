# 电源管理测试用例

实现：`app/power_manager/power_manager_app.c`。当前覆盖 3V3、5V 和网络桥接电源开关的上电控制。

## 验收概览

| 编号 | 测试内容 | 验收标准 | 结果 |
| --- | --- | --- | --- |
| PWR-001 | 上电初始化 | 三路负载开关按预期开启 | |
| PWR-002 | 电源输出 | 各路电压满足硬件规格 | |
| PWR-003 | 上电时序 | 外设在电源稳定后工作 | |
| PWR-004 | GPIO 配置异常 | 配置错误可报告且不会静默运行 | |
| PWR-005 | 长时间运行 | 电源状态稳定无异常切换 | |

## 详细用例

### PWR-001 上电初始化

1. 断电后接入测试仪器并上电。
2. 在启动阶段观察 3V3、5V、网络桥接开关输出。

预期：三路 GPIO 控制器 ready，输出状态为产品规定的 active 状态。

### PWR-002 电源输出

1. 分别测量三路输出电压和上电纹波。
2. 与硬件规格和负载条件比对。

预期：电压在规格范围内，网络和传感器模块可正常启动。

### PWR-003 上电时序

1. 使用示波器同时观察电源开关和外设复位/通信信号。
2. 重复冷启动 10 次。

预期：时序符合硬件要求，无因电源未稳定导致的偶发初始化失败。

### PWR-004 GPIO 配置异常

1. 使用专用错误 DTS 或测试板模拟 GPIO 控制器不可用。
2. 启动并观察日志和系统行为。

预期：明确报告错误；测试构建失败或受控停止，不得误报电源已开启。

### PWR-005 长时间运行

1. 满载运行 24 小时。
2. 监测三路电源和网络通信。

预期：无异常掉电、反复切换、通信中断或过热。

## 缺陷证据

附板卡版本、负载条件、示波器波形、电压测量值、启动日志和复现次数。
