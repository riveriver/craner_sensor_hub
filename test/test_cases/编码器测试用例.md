# 编码器测试用例

## 1. 测试信息

- 模块：`module/encoder_sample_service`。开发人员填写输入接口、脉冲/转数、采样周期、允许误差 ______。
- 工具：编码器模拟器或标准转台、示波器、串口/MQTT Shell、记录表。

## 2. 用例

| 编号 | 内容 | 通过条件 |
|---|---|---|
| ENC-001 | 静止零值 | 零速和位置稳定 |
| ENC-002 | 已知转速和方向 | 方向、速度和换算正确 |
| ENC-003 | 边界频率 | 范围内正确，超范围可控 |
| ENC-004 | 断线恢复 | 故障可识别且自动恢复 |

### ENC-001 静止零值
1. 使编码器停止，稳定 ______ s。
2. 通过 Shell 或业务接口读取位置、速度和状态 ______ 次。
3. 通过标准：位置不漂移，速度为零或在零速阈值内，无错误。

### ENC-002 已知转速和方向
1. 以 ______ rpm 正转和反转各运行 ______ s。
2. 记录位置增量、速度、方向和时间戳，与标准值计算误差。
3. 通过标准：方向正确，速度和脉冲换算误差不超过阈值。

### ENC-003 边界频率
1. 依次施加最低、额定和最高测试频率 ______。
2. 记录丢脉冲、溢出、错误状态和输出稳定性。
3. 通过标准：在声明范围内数据正确，超范围有明确错误或限幅行为。

### ENC-004 断线恢复
1. 运行采样时断开编码器输入，记录错误。
2. 恢复输入并观察 ______ s。
3. 通过标准：故障可识别，恢复后自动继续采样，不需重启。
