实现：`module/encoder_sample_service`、`app/encoder_app`。

## 验收概览

| 编号 | 测试内容 | 验收标准 | 结果 |
| --- | --- | --- | --- |
| ENC-001 | 正常采样 | 角度、圈数和时间戳持续更新 | |
| ENC-002 | 采样精度 | 方向、比例和边界值符合协议 | |
| ENC-003 | 离线检测 | 无响应后正确置为离线 | |

## 详细用例

### ENC-001 正常采样

1. 接入编码器模拟器或校准实物。
2. 施加静止、正向和反向运动。
3. 读取对应数据模型寄存器。

预期：采样周期符合配置，角度、圈数、时间戳和错误码持续更新。

### ENC-002 采样精度

1. 输入 0、正向边界、反向边界和跨零点数据。
2. 与模拟器输入和发布协议换算结果比对。

预期：符号、比例、字节序和边界值正确，无溢出。

### ENC-003 离线检测

1. 停止编码器响应。
2. 等待超过配置的离线阈值。

预期：离线状态和健康事件置位，连续失败统计增加，采样线程不阻塞。

### ENC-004 离线恢复

1. 恢复编码器响应。
2. 观察后续采样结果。

预期：离线状态清除，数据恢复更新，健康事件恢复在线。

### ENC-005 采样统计

1. 先执行稳定采样，再制造连续失败。
2. 通过已提供的采样统计入口查询。

预期：成功数、失败数、连续失败数和耗时与实际操作相符。

### ENC-006 多路映射

1. 同时接入回转、变幅和起升编码器。
2. 给每一路施加不同的明显输入。

预期：每一路数据只写入自己的寄存器区域，单一路故障不影响其他路。

## 缺陷证据

附编码器型号、串口参数、输入值、原始帧、寄存器响应、统计输出和复现次数。
